# SPYFALL: RIFT EDITION

Небольшая браузерная онлайн-игра в стиле Spyfall с тематикой League of Legends. Это неофициальный фан-проект.

## Возможности первой версии
- Онлайн-комнаты по пятизначному коду (3–10 игроков).
- Создатель комнаты — ведущий.
- Приватная раздача роли: игроки видят секрет, шпионы — нет.
- Категории: чемпионы, регионы, предметы, способности.
- Голосование за подозреваемого.
- Раскрытие результата и возможность шпиону попробовать угадать секрет.
- Список чемпионов загружается из Riot Data Dragon (русская локализация); при недоступности используется встроенный запасной список.

## Запуск на своём компьютере

Нужен Node.js 18 или новее.

```bash
npm install
npm start
```

Открой `http://localhost:3000`.

Чтобы протестировать с друзьями в одной локальной сети, открой порт 3000 в локальной сети и дай им адрес компьютера-хоста. Для игры через интернет нужен публичный хостинг.

## Публикация в интернете (например, Render)
1. Создай GitHub-репозиторий и загрузи туда все файлы проекта.
2. На Render создай **New → Web Service** и подключи репозиторий.
3. Build command: `npm install`
4. Start command: `npm start`
5. После публикации открой выданный HTTPS-адрес и отправь его друзьям.

Сервер использует Socket.IO и обычный HTTP-сервер, поэтому при выборе платформы проверь, что она поддерживает WebSocket. Для одного экземпляра сервера дополнительная база данных не нужна: комнаты хранятся в памяти и исчезнут при перезапуске.

## Важно
- Пока нет аккаунтов, постоянной статистики, восстановления комнаты после перезапуска или защиты от намеренного читерства.
- Не обновляй страницу во время раунда: в этой первой версии переподключение не восстанавливает приватную роль.
- Голосовое общение происходит отдельно (например, в Discord).
- Riot Games и League of Legends не связаны с этим фан-проектом. Названия и игровые данные принадлежат их правообладателям.

## Структура
- `server.js` — сервер комнат и игровая логика.
- `public/index.html` — интерфейс.
- `public/style.css` — оформление.
- `public/app.js` — клиентская логика.
